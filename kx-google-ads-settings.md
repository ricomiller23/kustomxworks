# Google Ads Campaign Settings & Implementation Guide

**Primary Domain**: https://kustomxworks.com

## 1. Campaign Architecture Overview

| Parameter | Setting Value | Rationale |
|---|---|---|
| **Campaign Name** | `KustomXworks - Search - Inland Empire` | Single organized Search campaign |
| **Campaign Type** | Search (Text Ads) | High-intent local emergency & project searches |
| **Networks** | Google Search Network ONLY | **Disable** Search Partners & Display Network |
| **Bidding Strategy** | **Phase 1**: Maximize Clicks (Max CPC: $7.00)<br>**Phase 2**: Maximize Conversions (tCPA: $80–$120) | Prevents runaway CPCs before Google learns conversion signals |
| **Daily Budget** | **Lean**: $65/day ($2,000/mo)<br>**Standard**: $115/day ($3,500/mo) | Focused local search capture |
| **Ad Schedule** | Monday – Sunday, 6:00 AM – 10:00 PM PST | Matches customer calling hours |
| **Languages** | English, Spanish | Inland Empire demographics |
